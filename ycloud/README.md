Домашнее задание по теме Яндекс Cloud.

Описание:
- В ноутбуке Zeppelin собирается простая витрина на основе нескольких
таблиц (users, orders, products) в PySpark.
- Производится вычисление производной метрики revenue и агрегирование данных по нескольким ключам (city,
product_id, product_name).
- Датафреймы объединяются по ключам (join) и
вычисляется Top‑2 продукта по группе с использованием оконных
функций.
- Результаты сохраняются в формате Parquet в
файловое хранилище (HDFS) с режимом overwrite.

Используемые инструменты:
- Yandex Cloud
- Apache Zeppelin.
- Apache Spark / PySpark.
- HDFS
- Git
